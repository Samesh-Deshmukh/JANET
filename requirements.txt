# --- Removed, and why (so nobody re-adds them by reflex) ---
# Audited 2026-09-05 against every `import` in src/ and tools/. The rule used:
# pin what JANET imports, plus what a dependency needs but will not install for
# itself (matplotlib, accelerate). Everything below was neither.
#
#   keyboard, pynput  - legacy push-to-talk, zero imports since Block 2. (evdev
#                       stayed only because utils/hotkey.py still imports it.)
#   pyttsx3           - superseded by the direct espeak-ng call in audio/tts.py.
#   sounddevice,      - never imported; PyAudio does capture and audio stays in
#   wavio               memory as a NumPy array rather than going via a wav file.
#   pandas            - never imported; intent/dataset.py reads plain text files.
#   tqdm              - never imported; transformers pulls in its own copy, so
#                       pinning it here only constrains a version JANET doesn't own.
#   rich, typer       - never imported; JANET's CLI surface is plain print().
#   PyYAML            - never imported; config is .env via python-dotenv.
#   psutil,           - never imported; leftovers from an earlier system-status
#   screeninfo          and screen-geometry idea that Linux never needed.
#   pyFirmata,        - Arduino placeholders for hardware work that has no code
#   pyserial            yet. Re-add them the same day something imports them.
#
# Earlier removals, from the Windows -> Linux move:
#   pyinput      - depends on Windows-only pywin32 (broke the whole install); the
#                  package you actually import is `pynput`, not `pyinput`.
#   PyGetWindow  - Windows/macOS window management; raises NotImplementedError on Linux.
#   PyRect       - only a dependency of PyGetWindow.
