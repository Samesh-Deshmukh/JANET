# JANET - Python 3.11 (Linux)

# will use it automatically.
--extra-index-url https://download.pytorch.org/whl/cu128

# --- Speech-to-text (OpenAI Whisper, GPU-accelerated) ---
torch==2.11.0+cu128
openai-whisper==20250625
silero-vad==5.1.2        # LSTM voice-activity detection; model caches locally after first run

# --- Audio I/O ---
# Capture is PyAudio and nothing else.
PyAudio==0.2.14

# --- Text-to-speech (Piper, local neural TTS) ---
# Replaced espeak-ng as JANET's voice. Cheap to add here: its only heavy
# dependency, onnxruntime, is ALREADY installed as a dependency of silero-vad
# above, so this pulls in just piper-tts + pathvalidate (~1 MB of wheels).
#
# The wheel is self-contained — it bundles its own espeak-ng data for
# phonemisation, so there is no system package to install for Piper itself.
# GPL-3.0, which matches JANET's own licence.
#
# Voice models are NOT pip-installed and NOT in this repo: audio/tts.py
# downloads the ~63 MB .onnx to ~/.local/share/piper-voices on first run, the
# same way Whisper and the NLI gate fetch theirs. JANET_NO_DOWNLOAD=1 is
# honoured for offline installs.
#
# `paplay` (PipeWire) is still a SYSTEM binary and still required — it is what
# plays the audio. `espeak-ng` is also still a system binary, but is now only
# the fallback voice, used when the Piper model can't be loaded.
piper-tts==1.8.0

# --- Push-to-talk (dormant) ---
# utils/hotkey.py has imported evdev since before Block 2 made JANET
# always-listening. Nothing imports hotkey.py any more, so this is dead weight —
# but it is a real import, so removing the pin breaks that file rather than
# merely shrinking the install. Delete both together if you want it gone.
evdev==1.9.3

# --- ML / data ---
numpy==2.2.6
scipy==1.15.3            # resample_poly for the 44.1kHz mic fallback (audio/audio.py, audio/vad.py)
scikit-learn==1.7.2      # metrics + the confusion matrix in intent/train.py
matplotlib==3.10.5       # NOT unused: scikit-learn's ConfusionMatrixDisplay draws through
                         # matplotlib but only declares it an optional extra, so intent/train.py
                         # would crash on savefig() after the fine-tune had already run.
transformers==5.2.0
accelerate==1.14.0       # required by the HuggingFace Trainer for DistilBERT fine-tuning (intent/train.py)

# --- Removed ---
# Audited 2026-09-05 against every `import` in src/ and tools/. The rule used:
# pin what JANET imports, plus what a dependency needs but will not install for
# itself (matplotlib, accelerate). Everything below was neither.
#
#   keyboard, pynput  - legacy push-to-talk, zero imports since Block 2. (evdev
#                       stayed only because utils/hotkey.py still imports it.)
#   pyttsx3           - superseded by audio/tts.py, which now calls Piper
#                       directly (and espeak-ng only as a fallback).
#   sounddevice,      - never imported; PyAudio does capture and audio stays in
#   wavio               memory as a NumPy array rather than going via a wav file.
#   pandas            - never imported; intent/dataset.py reads plain text files.
#   tqdm              - never imported; transformers pulls in its own copy, so
#                       pinning it here only constrains a version JANET doesn't own.
#   rich, typer       - never imported; JANET's CLI surface is plain print().
#   PyYAML            - never imported; config is .env via python-dotenv.
#   psutil,           - never imported; leftovers from an earlier system-status
#   screeninfo          and screen-geometry idea that Linux never needed.
#   pyFirmata,        - Arduino placeholders for hardware work that has no code
#   pyserial            yet. Re-add them the same day something imports them.
#
# Earlier removals, from the Windows -> Linux move:
#   pyinput      - depends on Windows-only pywin32 (broke the whole install); the
#                  package you actually import is `pynput`, not `pyinput`.
#   PyGetWindow  - Windows/macOS window management; raises NotImplementedError on Linux.
#   PyRect       - only a dependency of PyGetWindow.
